English Year 1 - Offline Package
=================================

How to open:
1. Keep all files in this folder together, including lunchbox.html and three.min.js.
2. Double-click index.html to open it in your browser.

That's it - no internet connection or server required. The Lunchbox activity
uses the included three.min.js file. Its web fonts use local fallbacks when
offline. If audio/video autoplay
or fullscreen behave oddly on your browser, you can alternatively run a local
server from this folder, e.g.:
  python3 -m http.server 8000
then visit http://localhost:8000

Scoops (under Lunchbox in Unit 4) opens the live website inside the page.
Scoops and Numbers Quiz require an internet connection.

Page music fades out and pauses while an embedded activity is expanded,
then fades back in when the activity closes. The first click outside the
activity closes it; a subsequent outside click closes the unit overlay.
